Conosci i livelli di inquinamento atmosferico, in tempo quasi reale, in molte località del mondo, inclusa la tua casa.

Aggiungi uno o più monitor virtuali della qualità dell'aria esterna a Homey. Le informazioni sono rese disponibili gratuitamente da diversi servizi. A seconda del servizio e della stazione selezionati, vengono forniti i seguenti parametri:

* PM1 (particolato sottile, disponibile con Luftdaten)
* PM2.5 (particolato sottile)
* PM10 (particolato sottile)
* CO2 (anidride carbonica, disponibile con Luftdaten)
* O3 (ozono)
* SO2 (biossido di zolfo)
* NO2 (biossido di azoto)
* CO (monossido di carbonio)
* BC (carbonio nero, disponibile solo con LuchtmeetnetNL e OpenAQ in alcuni paesi)
* Temperatura (disponibile con Luftdaten)
* Pressione (disponibile con Luftdaten)
* Umidità (disponibile con Luftdaten)
* Rumore (disponibile con Luftdaten)

Note sulla chiave API:
* OpenAQ (v3 API): Ottieni una chiave API gratuita su https://explore.openaq.org/register e inseriscila nelle impostazioni del dispositivo OpenAQ, oppure lascia vuoto per utilizzare la chiave Homey integrata.
* WAQI: Token personalizzato opzionale nelle impostazioni del dispositivo, oppure lascia vuoto per utilizzare la chiave Homey integrata.

Questa app utilizza:
* API OpenAQ per il recupero dei dati: https://docs.openaq.org/
* API Luftdaten / Sensor.Community per il recupero dei dati: https://sensor.community/it/
* API World Air Quality Index (WAQI) per il recupero dei dati: http://waqi.info/
* API Luchtmeetnet NL per il recupero dei dati: https://api.luchtmeetnet.nl/
* Dati forniti dalle agenzie mondiali di protezione ambientale: http://aqicn.org/sources/
